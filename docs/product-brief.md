# Product Brief

## 目的

艦船設計、艦隊編成、リアルタイム海戦、キャンペーン分岐を組み合わせた Web ゲームを作る。プレイヤーは自作艦を中心に艦隊を編成し、海域ミッションで敵艦隊、航空部隊、潜水艦、巨大兵器と戦う。

## 参照元から抽出する体験要素

Wikipedia の記事では、参照元ゲームの特徴として以下が挙げられている。

- 3D 化された自作艦の表示
- 自艦、従属艦、支援艦隊を含む大規模な艦隊投入
- 航空機部隊への個別指令、爆撃支援、揚陸隊などの戦略要素
- 水上艦、潜水艦、潜水空母、航空機の設計
- 条件付きの特殊・巨大兵器の使用
- 応急修理、修理ドック、二次災害回復
- ルート選択によるマルチシナリオ

本作ではこれらを直接コピーせず、Web 向けに以下へ再構成する。

## コアゲームループ

1. 研究・報酬で部品を得る
2. 艦船や航空隊を設計する
3. 艦隊を編成する
4. ミッション海域へ出撃する
5. リアルタイム戦闘で目標を達成する
6. 戦果、回収物、経験値、キャンペーン分岐を解決する
7. 次の設計とミッション選択へ戻る

## 初期 MVP

MVP は「小さくても検証可能な戦闘」を目標にする。

- 2D 俯瞰または軽量 3D の海域
- プレイヤー艦 1 隻
- 敵艦 3 種類
- 主砲、魚雷、対空砲の 3 系統
- 1 ミッション、1 ボス
- 簡易設計画面
- seed 固定のリプレイ再生
- Playwright によるブラウザ E2E

## 将来スコープ

## 設計モードの砲台高と干渉判定

主砲・副砲・対空砲は甲板からの砲台高を 0 / 2 / 4 / 6 / 8 m で指定できる。新規配置は上部の「新規砲台高」、既設砲塔は選択パーツの「砲台高」で変更する。高さは左右対称配置、コピー、移動、保存、取り消し・やり直し、出撃時の外観に引き継ぐ。

設置方向の砲身を口径・砲身長・砲門数から立体の占有範囲へ変換し、他の砲身、砲塔、台座、艦橋、煙突、甲板上の設備との干渉を拒否する。設置・移動・回転・高さ変更で同じ判定を用いる。砲身が下の砲塔を十分に越える段違い配置は可能だが、台座の設置面積の重なりは許可しない。船内機関は砲身と干渉しない。砲身だけの舷外への張り出しは可能。

配置図には砲身の占有範囲、側面図と 3D ドックには高さと台座を表示する。干渉が残る旧設計は警告を出し、修正するまで出撃できない。旧セーブの高さ省略は 0 m として扱い、配置を自動変更しない。高さ変更による追加重量や火力補正はない。判定は設置方向で行い、戦闘中の全旋回範囲や砲弾の射線遮蔽は対象外。

設計図の部品は、上面図・側面図・パレットで種類別の SVG 図版を使う。砲塔の装甲面・旋回リング・ハッチ、艦橋の階層・窓・マスト、煙突の排気格子、魚雷発射管、ミサイル発射架／VLS、ボイラーの胴体・配管、タービンの軸・ケーシングを描き分ける。図版は既存の配置面積と回転に合わせて表示し、配置選択枠はホバー・選択時に表示する。砲身の位置と長さには既存の干渉判定と共通の寸法を使う。

砲身の表示寸法は砲諸元の全長をそのまま砲塔前面へ加算せず、砲塔内の部分を差し引いた概略比率で求める。コンパクトな配置用砲塔に合わせて突出部分にも上限を設け、図面・3D モデル・干渉判定で共有する。これは外観用の比率補正で、射程・散布界など戦闘用の砲諸元は変更しない。

## 一画面の図面ワークスペース

側面図と上面図を中央に配置し、画面高に合わせて縦横比を維持したまま収める。部品一覧・搭載表・性能・防御は同じサイドパネルのボタンで切り替え、長い内容のみパネル内でスクロールする。狭い画面では同じパネルを図面の下に置く。選択部品の回転・微移動・砲台高・削除は図面上部へ集約し、重量・速力・出撃可否は下端に常時表示する。部品名の検索と、設計警告から性能パネルへの移動を用意する。

部品の描画は参考画像のような細線の図面表現に統一する。兵装は黄系、機関は青緑、艦橋・煙突・船体は淡い線で描き、上部構造の配置中も船内機関の輪郭を薄く表示する。機関の薄い輪郭はクリックを遮らず、編集するには「船内機関」へ切り替える。船体外形は配置可能な船体マスクから作る。

設計部品をドラッグしている間は、上面図・側面図・3D ドックが同じ移動プレビューを参照する。側面図でも前後にドラッグでき、左舷／右舷の位置と砲台高を維持する。コピーのプレビューでは元の部品を残す。移動中の仮配置は保存・出撃データや取り消し履歴に書き込まず、配置可能な位置へのドロップだけを一操作として確定する。Esc・pointer cancel・ポインター捕捉の喪失・ウィンドウのフォーカス喪失では確定しない。上面図の船体外ドロップによる削除は従来通り。

部品図版では砲塔を大口径の傾斜装甲型と小口径の丸みのある防盾型に分け、測距儀・砲眼・旋回部を描く。艦橋は駆逐艦型・塔型・戦艦型の輪郭を使い分ける。煙突は後方へ傾斜した筒体と蒸気管を、機関はボイラーのドラムと高低圧タービン・継手・軸を描く。部品一覧の砲は砲身も含めた全体形状を表示し、その長さには設計図と同じ寸法を用いる。
