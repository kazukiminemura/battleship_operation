# Blender製の戦艦外観

戦艦系の船体・艦橋・砲塔装甲・砲身・煙突をBlender 4.5で制作した部品に置き換えています。
特定の実在艦の完全な複製ではなく、第二次大戦期の戦艦を意識したオリジナルのゲーム用造形です。
駆逐艦・巡洋艦の外観、艦の性能・当たり判定・保存形式は変更しません。

## 編集と再生成

- `assets/blender/battleship-kit.blend`：編集可能なBlenderファイル。組み立て例と再利用用の部品コレクションを含みます。
- `scripts/blender/build_battleship.py`：造形と書き出しの再現用スクリプト。
- `src/game/rendering/assets/battleship-kit.json`：面取り・法線を適用したゲーム用の索引付きメッシュ。

再生成する場合は、リポジトリで次を実行します（Blenderの実行ファイルをPATHに設定）。再生成は既存の `.blend` とメッシュを上書きするため、手作業で編集したモデルは別名保存してください。

```powershell
blender --background --factory-startup --python scripts/blender/build_battleship.py
```

船体曲面、赤い船底と水線帯、木甲板、手すり、錨鎖、係船柱、排水口、スクリュー・舵を含みます。
艦橋には観測甲板、窓、測距儀、梯子と支索。砲塔には傾斜装甲、面取り、照準窓、点検ハッチを持たせています。

追加のリアリティ調整では、傾斜船首・水中の球状船首・錨を制作し、水面から甲板までの高さを長さ比3.9%から2.8%へ調整。甲板と装備の座面も同じ比率を使います。
艦橋には探照灯・双眼鏡・斜め支柱・外階段を追加。砲身は段付き外筒・内壁のある砲口・布製防水覆いを持つ独立したBlender部品です。

## 設計・戦闘への接続

共通の `buildShip` がBlender部品を利用します。砲塔装甲には砲身を焼き込まず、砲身数と旋回はゲームの武装データから生成します。
艦橋・煙突も独立部品のため、設計画面で移動・回転・削除した結果を維持します。
`.blend` の組み立て例は確認用であり、ゲームの武装数を変更しません。

船体28,508、艦橋10,136、砲塔装甲1,692、煙突4,872、砲身1本884三角形。各部品は材質別にまとめ、GPU形状を艦同士で共有します。
ゲーム用メッシュは同期読み込みなので、描画途中の読込完了が新しい設計を上書きしません。代わりに初回の配信データが増えます。

## 検証

`npm run build`、`npm test`。専用テストはメッシュの索引・法線・三角形数、艦種別の適用範囲、形状の共有と座標の独立性、砲身数・回転を検査します。
既存の設計→戦闘テストは自由配置と装備削除の維持を検証します。
稼働中の開発サーバーに対して `node scripts/capture-historical-ships.mjs --blender` で両画面の実際のモデルを確認できます。
