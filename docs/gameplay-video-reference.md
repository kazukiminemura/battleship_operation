# 添付プレイ動画を基にした砲戦の調整

参考: ユーザー添付「【38センチ砲撃ちまくり】鋼鉄の咆哮3 K-06『見えない恐怖』Part1」。約4分43秒、960×720、30fps。2026-10-18にフレームを抽出し、全体の等間隔サンプルと、下記区間の1秒間隔の連続フレームを比較した。音声・入力履歴の解析や原作の実機操作は行っていない。

## 確認できた挙動と採用する設計

| 区間 | 動画で確認した挙動 | 本作での対応 |
| --- | --- | --- |
| 00:32–00:39 | 自艦中心の追従画面。航跡を残して航行し、敵艦と接近する | 操艦と照準を同時に継続できる入力にする。カメラが動いてもカーソル位置から照準を毎tick計算する |
| 01:12–01:19 | 進路を変えながら連続する砲撃・着弾。複数の敵艦が旋回して接近する | 主砲・副砲の装填を短縮し、敵艦を接近→射程内での旋回→近すぎる場合の離脱へ変更する |
| 02:10–02:17 | 航行を続けながら港湾施設へ砲撃し、施設に炎が残る | 既存の施設への射撃、破壊後の大きさ・炎、航跡を維持する |
| 03:18–03:25 | 複数艦が異なる針路で接近し、曲がった航跡と着弾水柱が残る | 艦IDから左右の旋回方向を固定し、同じ方向へ全艦が集中するのを避ける。既存の艦同士・海岸の回避を併用する |

動画からマウスの押下状態や正確な装填時間は判別できない。左ボタン長押しによる継続射撃と以下の数値は、この観察を基にした本作の設計判断であり、原作の操作仕様・数値を再現したものではない。

## 今回の操作と数値

- 海面を左ボタンで押すと選択中の兵装を発射し、押している間は装填完了後に再発射する。数字キーで兵装を切り替える。短いタップも1回の射撃要求として残す。
- 手動で射撃要求を出している兵装は、そのtickの自動照準より優先する。ほかの兵装の自動射撃は従来どおり。射角・射程外では発射しない。
- HUD上、画面外、ポーズ、フォーカス喪失、ポインター操作のキャンセル、戦闘以外の画面で継続射撃しない。
- 標準主砲は1.8秒、12.7cm APは1.5秒、15.2cm砲は1.8秒、20.3cm砲は2.4秒、40.6cm HEは3.2秒、40.6cm APは3.6秒、46cm砲は4.5秒、ボス砲は5秒。副砲は0.8–1.2秒。実艦の装填時間を表す値ではない。
- 弾数・1発の威力・射程・散布界、魚雷・ミサイル・対空兵装の装填時間は変更しない。弾薬は有限で、砲塔と砲身数に応じて消費する。
- 既定の40.6cm APを射角内の静止目標へ30秒間連続発射する条件では、旧32秒装填の1斉射から、新3.6秒装填の9斉射になる。新しい回帰テストは発射間隔と実際の弾薬消費を検証する。

## 責務と検証

- `InputAdapter`: 押下・解除・照準位置から射撃要求を作る。装填やダメージの判定を持たない。
- `combatStep` / `weapons`: 手動射撃の優先、装填、射角、射程、弾薬消費を判定する。
- `naval-tactics.ts`: 接近・旋回・離脱の目標針路と速度を計算する。時刻や非決定的乱数を参照しない。
- `ai.ts`: 上記の針路を既存の衝突・海岸回避と組み合わせて命令を出す。
- `sustained-fire.test.ts` / `naval-tactics.test.ts`: 継続射撃、タップの重複防止、カメラ追従、兵装切替、HUD・キャンセル・ポーズ、手動照準の優先、移動しながらの射撃、seedの再現性、装填と弾薬を検証する。

添付動画は解析だけに使い、映像・音声・抽出画像を本番アセットに含めない。ブラウザでの目視・操作確認と、実プレイによる難易度・FPSの評価は未実施。
