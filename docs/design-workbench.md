# 艦船設計局の構成

2026-10-18。ユーザーの「設計システムを似せて」に対応。添付K-06動画には設計の部品配置操作が映っていないため、公式の[戦艦設計スクリーンショット](https://www.gamecity.ne.jp/kurogane/3/images/kuro3_01b.jpg)と[スクリーンショット一覧](https://www.gamecity.ne.jp/kurogane/3/screen.htm)を構成の参考にした。

## 操作

- 兵装・機関・設備・防御の区分で部品を絞り込む。右の部品一覧から選択・ドラッグして、上面図へ配置する。
- 側面図と上面図を同時表示。側面図も同じHLG部品の座標・寸法を使い、クリックまたはキーボードで部品を選べる。船首は左、船尾は右と両図に明記する。
- 上面図を「上部構造」「船内機関」に切り替え、重なっている主缶・主機を直接選択・移動できる。側面図の船内機関は赤系の断面線で表示する。
- 左右対称配置はチェックで切り替える。初期値は従来と同じ有効。対称側も配置可能な場合に追加し、同じ兵装スロットにまとめる。中央配置は1基。
- 部品の追加、対称ペアの追加、移動、コピー、削除、回転、装甲設定、標準配置・読込を40操作まで取り消し・やり直しできる。Ctrl/Cmd+Z、Ctrl/Cmd+Shift+Z、Ctrl+Yに対応。新しい編集はやり直し履歴を破棄する。船体・艦種の切替では履歴をリセットする。
- 下段の搭載兵装表で兵装スロット・同種部品の基数を管理し、隣の性能・防御欄へ反映する。「3Dドック」へ切り替えると既存の立体プレビューで確認できる。

## 実装境界

- `ShipBlueprint.tsx`: 側面図と部品記号。設計セルを投影し、部品選択を親へ返す。
- `ShipWorkbench.css`: 図面、部品一覧、搭載表、性能欄の配置と外観。狭い画面は図面を先頭に縦並びへ切り替える。
- `design-history.ts`: 設計全体の変更履歴。Reactの状態更新と同じ関数形式を受け、設計スナップショットを保持する。
- `design-placement.ts`: レイヤー分類、対称セル、対称ペアの生成。配置可否は既存HLGルールへ委譲する。
- 保存するHLGDesignと出撃データの形式は変更しない。性能計算・射角・重量・出撃可否は既存ルールを使い、履歴から戻した設計も同じ変換で戦闘へ渡す。

公式画像は比較用として参照し、本番アセットには使用していない。独自のSVG/CSSと既存モデルで描画する。Unitテストで対称ペアと戦闘スロット、履歴の原子性、重量・装甲・兵装の復元、履歴上限、船体切替を検証。Reactのサーバーレンダリングで初期設計画面を生成してエラーを確認した。ブラウザの目視・ドラッグ操作・E2Eは実行環境の制約で未実施。
