# ABYSS — 深海探査

小さな潜水艇を操縦し、沈没船・遺跡・熱水噴出孔・発光する群落・巨大な骨格を探索する3Dゲームです。

## 起動

`npm install`、`npm run dev` の順で実行し、表示されたサーバーURLの `/underwater.html` を開いてください。通常は http://localhost:5173/underwater.html です。
WebGL対応ブラウザが必要です。3Dモデル・音・海底地形はコードから生成され、外部素材のダウンロードは不要です。

## 遊び方

「探索をはじめる」で出発します。ソナーで近くの反応を発見し、画面右上の進路と深度案内を見ながら近づいてください。
調査地点から16m以内で推進を止め、Fを約2.5秒間押し続けると記録できます。5地点中3地点以上を調査し、基地から11m以内でFを押すとクリアです。残りの地点も任意で調査できます。

- W / S：前進・後退、A / D：旋回（矢印キーも対応）
- Q / E：上昇・潜航
- Shift：加速（バッテリーと酸素の消費増加）
- Space：ソナー（再送信まで5秒）
- F長押し：調査、基地では帰還
- Esc：一時停止・再開
- 調査記録：発見した場所の記録を読む（開いている間は停止）

狭い画面では下部のタッチ操縦ボタンを使えます。

酸素は通常航行で約9分。基地に戻ると酸素と船体を回復します。バッテリーは加速していない間に回復します。海底へ潜航し続けると船体が損傷します。
酸素または船体が尽きると探索終了になり、新しくやり直せます。保存されるのはクリア時の最高調査数のみで、途中の航行状態は保存されません。

## 確認

`npm test` で移動・調査・資源・帰還などのロジックを、`npm run build` で本番ビルドを確認できます。
開発サーバーを `127.0.0.1:5173` で起動した状態で `node scripts/verify-abyss.mjs` を実行すると、実際のキー操作で出発・一時停止・3地点調査・帰還・再挑戦を検証します。
ブラウザ検証には Playwright の Chromium が必要です。スクリーンショットは `docs/screenshots/` に出力されます。
