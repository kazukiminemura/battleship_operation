# 艦種別の歴史的外観

第二次大戦期の艦影に寄せたゲーム用の意匠。実在艦の寸法・兵装数を完全再現するモデルではない。

| 艦種 | 外観の方向 | 実装 |
| --- | --- | --- |
| 駆逐艦 | 吹雪型時代の細身の艦影 | 長幅比10.2、低い閉鎖式艦橋、二本煙突、鋼甲板、艦尾の爆雷格納架 |
| 巡洋艦 | 高雄型時代の大型艦橋 | 長幅比9.0、張り出しのある艦橋、二本煙突、木甲板、艇揚収クレーン |
| 戦艦 | 大和型を意識した上部構造 | 長幅比7.3、塔型艦橋、大型一本煙突、大型測距儀、条件に合う主砲の背負い式砲座 |

比率は画面上の視認性を含めて決めた造形値。共通で船首の反り、三脚マスト、支索、艇、係船設備を持つ。煙突は自由配置武装と干渉すると近隣へ移す。配置可能な空間がない場合は省略する。

## ゲームとの接続

艦種プロファイルと固定構造物は独立した描画モジュールに集約。設計・戦闘の両画面は同じbuildShipを使用する。装備数・砲身数・自由配置座標は入力を維持し、装飾の主砲は追加しない。ゲーム固有の誘導弾等も搭載時は表示する。艦の性能・当たり判定・セーブ形式は変更しない。

初期設計は現在各艦種とも描画上の武装が1基。戦闘の標準編成は駆逐艦2、巡洋艦6、戦艦8の武装オブジェクトを持つ。この差は既存の装備データによるもの。

## 確認

`node scripts/capture-historical-ships.mjs` で、稼働中のローカル開発サーバーから実際の初期設計・標準戦闘装備を使った六枚のプレビューと戦闘画面を保存する。

- `historical-*-designer.png`: 初期設計
- `historical-*-combat.png`: 標準戦闘装備
- `historical-combat.png`: 実戦闘画面

専用テストは三艦種の構造・煙突数、武装の保持、自由配置、船首甲板の連続性を検証する。全97テストと本番ビルド成功。
